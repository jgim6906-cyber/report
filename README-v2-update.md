# v2 업데이트 안내 — 다중 부서 + 인원 관리

기존에 등록하신 프로젝트에 아래 내용을 반영하면 됩니다.

## 1단계. Supabase에 마이그레이션 SQL 실행

1. Supabase 대시보드 → **SQL Editor**
2. `migration-v2.sql` 파일 내용을 전체 복사해 붙여넣고 **Run**
   - `weekly_reports` 테이블에 부서 구분(`dept_key`) 컬럼이 추가됩니다.
   - 부서별 인원 명단을 저장하는 `rosters` 테이블이 새로 생깁니다.
   - 업무PM팀 명단은 기존 11명이 자동 등록되고, 공사PM팀은 빈 명단으로 시작합니다 (화면에서 "인원관리" 탭으로 직접 추가).

⚠️ **참고**: 예전 코드는 인원을 "이름"으로 저장했지만 새 코드는 인원 고유 id로 저장합니다. 그래서 지난주까지 입력해두신 업무내용/근태 데이터는 새 화면에서는 비어 보일 수 있습니다. 이번 주부터는 정상적으로 저장·조회됩니다.

## 2단계. 새 index.html로 교체

1. 새로 받으신 `index.html`의 상단에서 아래 두 줄을 기존에 쓰시던 값으로 다시 입력해주세요.
   ```javascript
   const SUPABASE_URL = 'https://YOUR-PROJECT-REF.supabase.co';
   const SUPABASE_ANON_KEY = 'YOUR-ANON-PUBLIC-KEY';
   ```
2. GitHub 저장소의 기존 `index.html`을 이 새 파일로 덮어쓰기(교체) 업로드하세요.
3. Vercel은 GitHub과 연동되어 있으므로 저장소에 새 파일을 올리면 **자동으로 재배포**됩니다. (몇십 초 정도 소요)

## 새로 추가된 기능

### 1) 인원 관리 탭
- 각 부서(업무PM팀/공사PM팀) 화면에 **"인원관리"** 탭이 새로 생겼습니다.
- **+ 인원 추가** 버튼으로 신규 입사자를 추가할 수 있습니다.
- 직급/이름을 표에서 직접 클릭해 바로 수정할 수 있습니다.
- **부서장** 체크박스: 엑셀 다운로드 시 "부서원" 시트에서 제외되는 관리자를 표시합니다.
- **삭제** 버튼으로 퇴사자를 명단에서 제거할 수 있습니다 (그동안 입력된 업무내용/근태 기록은 보존됩니다).
- 인원 변경은 요일별 합계, 엑셀 다운로드 등 모든 곳에 **자동으로 반영**됩니다.

### 2) 부서 전환 (업무PM팀 / 공사PM팀 / PM실 통합)
- 상단에 부서 전환 버튼이 생겼습니다.
- **업무PM팀 / 공사PM팀**: 완전히 독립된 명단·업무내용·근태 데이터를 가집니다. 각자 따로 입력·저장됩니다.
- **PM실 (통합)**: 두 부서 데이터를 한 화면에서 함께 조회하는 **읽기 전용** 대시보드입니다.
  - 업무내용/특이사항 탭: 부서명 구분 행 아래로 두 팀 인원이 모두 표시됩니다 (수정 불가, 각 부서 탭에서 수정).
  - 연차·외근·도시락 탭: 두 팀을 합산한 요일별 합계만 표시됩니다.
  - 엑셀 다운로드 시 업무PM팀 시트 + 공사PM팀 시트 + PM실 통합요약 시트, 총 3개 시트가 담긴 파일이 만들어집니다.

## 공사PM팀 인원 최초 등록 방법

1. 상단에서 **공사PM팀** 버튼 클릭
2. **인원관리** 탭 이동
3. **+ 인원 추가**로 인원 수만큼 행 추가 → 직급/이름 입력
